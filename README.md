# Portafolio Personal Neobrutalista - Sergio Daniel Florez Lopez

Sitio web personal de una sola página desarrollado con **HTML5 semántico, CSS3 moderno y JavaScript vanilla puro** (sin frameworks, sin Tailwind, sin Bootstrap, sin dependencias externas).

---

## 🎨 Identidad Visual y Estilo

- **Estética**: Neobrutalismo profesional, editorial y técnico (estilo laboratorio de sistemas / libreta de ingeniería).
- **Paleta de Colores**:
  - Fondo Base: `#FFF8E7`
  - Superficie / Tarjetas: `#FFFFFF`
  - Texto y bordes: `#111111`
  - Azul principal: `#145CFF`
  - Amarillo acento: `#FFD43B`
  - Verde secundario: `#5FE35B`
  - Rojo de alertas: `#FF5C5C`
- **Tipografías**:
  - *Space Grotesk* (titulares contundentes)
  - *IBM Plex Mono* (etiquetas técnicas, métricas, código y metadatos)

## ⚙️ Guía de Personalización Rápida

Dentro de `index.html` encontrarás comentarios explicativos en mayúsculas como `<!-- REEMPLAZA CON ... -->` para facilitar la edición de:

1. **Datos de Contacto y Redes Sociales**:
   - `mailto:sergio.florez@ejemplo.com` en la sección de contacto.
   - Enlace a tu perfil de **GitHub**: `https://github.com/sergioflorez`
   - Enlace a tu perfil de **LinkedIn**: `https://linkedin.com/in/sergioflorez`
2. **Proyectos**:
   - Cada tarjeta de proyecto cuenta con los dos botones solicitados:
     - `[ Código Git ]`: Enlace hacia tu repositorio específico.
     - `[ Ver página ]`: Enlace al despliegue en vivo, demo o documentación.
   - Puedes ajustar los títulos, problemas, soluciones técnicas, etiquetas de tecnologías y las métricas destacadas.
3. **Imagen de Cabecera**:
   - Se encuentra vinculada a `assets/sergio-hero.png`. Si deseas sustituirla por otra fotografía o ilustración, solo reemplaza el archivo en la carpeta `assets/`.

## 🚀 Cómo Visualizar el Portafolio

Al ser un proyecto estático sin dependencias, puedes abrirlo directamente:

1. Abre el archivo `index.html` directamente en tu navegador habitual (haciendo doble clic en él o arrastrándolo a Chrome, Edge o Firefox).
2. O bien, si tienes la extensión *Live Server* en VS Code / tu editor, haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"**.
